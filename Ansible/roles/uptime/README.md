# uptime

## Русский

Развертывает Uptime Kuma как проект Docker Compose v2 на хосте с уже установленным Docker. Мониторы и уведомления настраиваются вручную в веб-интерфейсе и не входят в задачи роли.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Deploys Uptime Kuma as a Docker Compose v2 project on a host with Docker already installed. Monitors and notifications are configured manually in the web UI and are out of the role scope.

Full documentation: [README_ENG.md](README_ENG.md)
