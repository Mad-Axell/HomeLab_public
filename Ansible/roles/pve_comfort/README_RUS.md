# pve_comfort

Роль готовит узел Proxmox VE к повседневной работе:

- отключает enterprise-репозитории PVE и Ceph;
- удаляет устаревшие однострочные файлы репозиториев
  (`pve-no-subscription.list`, `pve-install-repo.list`), включая запись
  bookworm, оставленную установщиком;
- включает официальный репозиторий no-subscription в формате deb822 по HTTP с
  проверкой подписи через `Signed-By` (HTTPS к `download.proxmox.com` в этой
  сети не проходит проверку TLS);
- обновляет индексы и устанавливает системные обновления;
- устанавливает набор административных утилит;
- создаёт отдельного администратора в группах `sudo` и `adm`;
- при необходимости устанавливает его публичные SSH-ключи;
- сообщает о необходимости перезагрузки, но не перезагружает узел сама.

Обязательны `pve_comfort_admin_user` и `pve_comfort_admin_password`. Обработка
пароля закрыта `no_log`. Плейбук должен идти последовательно по одному узлу,
поскольку обновления могут перезапускать службы Proxmox.
