# sysctl_tunables

## Русский

Приводит объявленные параметры ядра к нужным значениям и сохраняет их в файле
под `/etc/sysctl.d`.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Brings the declared kernel parameters to their desired values and persists them
in a file under `/etc/sysctl.d`.

Full documentation: [README_ENG.md](README_ENG.md)
