# immich

## Русский

Разворачивает Immich как проект Docker Compose v2 на хосте с уже установленным Docker: сервер и контейнер машинного обучения, база и расширения на внешнем PostgreSQL, очередь на внешнем Redis. Обратный прокси Traefik и монтирование фотохранилища вне задач роли.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Deploys Immich as a Docker Compose v2 project on a host with Docker already installed: the server and the machine-learning container, a database and extensions on an external PostgreSQL, and a job queue on an external Redis. The Traefik reverse proxy and the photo storage mount are out of the role scope.

Full documentation: [README_ENG.md](README_ENG.md)
