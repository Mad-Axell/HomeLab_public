# vaultwarden

## Русский

Развертывает Vaultwarden (совместимый с Bitwarden сервер паролей) как проект Docker Compose v2 на хосте с уже установленным Docker. Токен админ-панели приходит из `VARS/secrets.yml` по имени переменной.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Deploys Vaultwarden (a Bitwarden-compatible password server) as a Docker Compose v2 project on a host with Docker already installed. The admin panel token comes from `VARS/secrets.yml` referenced by variable name.

Full documentation: [README_ENG.md](README_ENG.md)
