# dns_adguard

## Русский

Устанавливает и настраивает AdGuard Home как DNS-фильтр на Debian. Пароль администратора передается только внешним Vault-хэшем.

Полная документация: [README_RUS.md](README_RUS.md)

Installs and configures AdGuard Home as a DNS filter on Debian. The administrator password is supplied only as an external Vault hash.
