# loki

## Русский

Устанавливает Grafana Loki из официального APT-репозитория Grafana на Debian и
настраивает однобинарное развёртывание: хранилище на файловой системе,
retention через compactor и управляемый systemd-сервис.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs Grafana Loki from the official Grafana APT repository on Debian and
configures a single-binary deployment: filesystem storage, retention through
the compactor and a managed systemd service.

Full documentation: [README_ENG.md](README_ENG.md)
