# traefik

## Русский

Устанавливает Traefik как статический бинарный файл на Debian: выделенная учётная запись, systemd-юнит, HTTP→HTTPS редирект, file provider с динамической конфигурацией и опциональный TLS из внешнего сертификата и ключа.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs Traefik as a static binary on Debian: a dedicated service account, a systemd unit, an HTTP to HTTPS redirect, a file provider with dynamic configuration and optional TLS from an externally supplied certificate and key.

Full documentation: [README_ENG.md](README_ENG.md)
