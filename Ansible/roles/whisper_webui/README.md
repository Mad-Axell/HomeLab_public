# whisper_webui

## Русский

Устанавливает Whisper-WebUI: веб-интерфейс распознавания речи в текст на базе
faster-whisper с инференсом на CPU. Разворачивает релиз из tarball GitHub в
версионированный каталог, собирает venv с CPU-сборками PyTorch, настраивает
параметры по умолчанию и systemd-сервис.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs Whisper-WebUI: a speech-to-text web interface powered by
faster-whisper running CPU inference. Deploys a release from the GitHub
tarball into a versioned directory, builds a venv with CPU PyTorch wheels,
configures the default parameters and the systemd service.

Full documentation: [README_ENG.md](README_ENG.md)
