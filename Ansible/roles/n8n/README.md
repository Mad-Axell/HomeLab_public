# n8n

## Русский

Разворачивает n8n (автоматизация workflows) как проект Docker Compose v2 на хосте с уже установленным Docker, с базой на внешнем PostgreSQL и зафиксированным ключом шифрования учётных данных. Обратный прокси Traefik и создание учётной записи владельца вне задач роли.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Deploys n8n (workflow automation) as a Docker Compose v2 project on a host with Docker already installed, with a database on an external PostgreSQL and a pinned credential encryption key. The Traefik reverse proxy and the owner account setup are out of the role scope.

Full documentation: [README_ENG.md](README_ENG.md)
