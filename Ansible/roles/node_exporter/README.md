# node_exporter

## Русский

Устанавливает `prometheus-node-exporter` из пакетов Debian на любой наблюдаемый
хост и управляет его флагами через `/etc/default/prometheus-node-exporter`
(адрес и порт прослушивания, дополнительные коллекторы). Аналог `zabbix_agent`
для стека Prometheus.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs `prometheus-node-exporter` from the Debian packages on any monitored
host and manages its flags through `/etc/default/prometheus-node-exporter`
(listen address and port, extra collectors). The `zabbix_agent` counterpart for
the Prometheus stack.

Full documentation: [README_ENG.md](README_ENG.md)
