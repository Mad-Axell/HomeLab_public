# docker

## Русский

Устанавливает Docker Engine из официального репозитория Debian, управляет сервисом и по выбору добавляет существующих пользователей в группу `docker`.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs Docker Engine from the official Debian repository, manages the service, and optionally adds existing users to the `docker` group.

Full documentation: [README_ENG.md](README_ENG.md)
