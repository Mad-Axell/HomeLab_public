# add_users

## Русский

Создает и обновляет локальные учетные записи, их дополнительные группы и при необходимости добавляет пользователей в группу `sudo`. Хэши паролей передаются только через переменные Vault.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Creates and updates local accounts, their supplementary groups, and optionally adds users to the `sudo` group. Password hashes are supplied only through Vault variables.

Full documentation: [README_ENG.md](README_ENG.md)
