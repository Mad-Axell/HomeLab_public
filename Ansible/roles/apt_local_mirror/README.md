# apt_local_mirror

## Русский

Доставляет каталог APT-репозитория с Ansible-контроллера на целевой хост,
чтобы APT мог использовать его через `file://` без доступа в интернет.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Delivers an APT repository directory from the Ansible controller to the target
host so APT can consume it over `file://` without internet access.

Full documentation: [README_ENG.md](README_ENG.md)
