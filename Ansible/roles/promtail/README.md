# promtail

## Русский

Устанавливает Promtail — классический агент сбора логов Grafana Loki — из
официального APT-репозитория Grafana на Debian и настраивает отправку
journald и файлов `/var/log` в Loki.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs Promtail — the classic Grafana Loki log collection agent — from the
official Grafana APT repository on Debian and configures shipping of journald
and `/var/log` files to Loki.

Full documentation: [README_ENG.md](README_ENG.md)
