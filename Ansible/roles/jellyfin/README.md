# jellyfin

## Русский

Устанавливает медиа-сервер Jellyfin из официального APT-репозитория `repo.jellyfin.org`, ставит VAAPI-пакеты для аппаратного транскодирования и даёт сервисному пользователю доступ к `/dev/dri` через группы `render`/`video`. Пути медиа передаются входной переменной.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Installs the Jellyfin media server from the official `repo.jellyfin.org` APT repository, installs VAAPI packages for hardware transcoding and grants the service user `/dev/dri` access via the `render`/`video` groups. Media paths are supplied as a role input.

Full documentation: [README_ENG.md](README_ENG.md)
