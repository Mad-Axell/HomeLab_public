# homepage

## Русский

Развертывает панель gethomepage как проект Docker Compose v2 на хосте с уже установленным Docker и генерирует конфигурацию `services.yaml`, `widgets.yaml` и `settings.yaml` из входных переменных роли.

Полная документация: [README_RUS.md](README_RUS.md)

## English

Deploys the gethomepage dashboard as a Docker Compose v2 project on a host with Docker already installed and renders the `services.yaml`, `widgets.yaml` and `settings.yaml` configuration from role input variables.

Full documentation: [README_ENG.md](README_ENG.md)
