# netbox_seed

## Русский

Идемпотентно применяет объекты NetBox через REST API в порядке зависимостей: RIR, сайты, стойки, производители, роли, типы устройств, VLAN, кластеры, префиксы, устройства, VM, интерфейсы, MAC-адреса и IP-адреса. Полная документация: [README_RUS.md](README_RUS.md)

## English

Idempotently applies NetBox objects through the REST API in dependency order: RIRs, sites, racks, manufacturers, roles, device types, VLANs, clusters, prefixes, devices, VMs, interfaces, MAC addresses, and IP addresses. Full documentation: [README_ENG.md](README_ENG.md)
